## Зачем это нужно

Русскоязычным мастерам и игрокам обычно приходится прыгать между вики, PDF и таблицами. Здесь всё в одном окне:

- найти монстра по **опасности (CR / БО)**, типу и среде, когда готовите энкаунтер;
- отфильтровать **заклинания** класса по уровню, школе, ритуалу и концентрации;
- сравнить **виды / расы** и **предыстории** при создании персонажа;
- подобрать **магический предмет** по редкости и настройке;
- подсмотреть правило в **глоссарии 2024** или в статьях 2014 (сложность боя, яды, инвентарь и т. д.), не листая книгу.

Названия даны по-русски, английское имя всегда рядом — можно искать и `огненный шар`, и `Fireball`.

**Что важно знать про 2014:**

- Некоторые существа и расы представлены **несколькими версиями** (например, из *Mordenkainen’s Tome of Foes* и из *Monsters of the Multiverse*). В списке у них одинаковое название, различаются они по пометке источника (MToF, MPMM, VGtM…) справа внизу карточки в списке.
- Часть заклинаний (например, из *Modern Magic*) — **Homebrew / UA**; для них есть фильтр «Статус» и признак `homebrew: true` в данных.
- В «Правила и статьи» вошли рубрики: игровые механики, инвентарь, статьи о бестиарии и расах, lore, «Новичку».
- Homebrew-разделы (сообщество) в базу **не входят**.

Источники включают Player’s Handbook, Monster Manual, Dungeon Master’s Guide (2014 и 2024), Volo’s, Mordenkainen’s Tome of Foes, Monsters of the Multiverse, Xanathar’s, Tasha’s, Fizban’s, Eberron, Ravenloft, Forgotten Realms, Spelljammer, Planescape и другие официальные книги — с русскими названиями и английскими именами.

## Возможности

- Переключение редакций **2014 ↔ 2024** в шапке. Если запись есть в обеих, на карточке будет ссылка «Версия 2014 / 2024».
- Живой **поиск** по русскому и английскому названию.
- Десятки **фильтров** (свои для каждого раздела и редакции): опасность, тип, теги, размер, мировоззрение, среда, скорость, чувства, КД, хиты, иммунитеты и сопротивления, школа магии, класс и подкласс, ритуал, концентрация, тип урона, спасбросок, редкость, настройка, цена, требования черт, повышение характеристик, источник и другие.
- Сортировка по алфавиту, CR, уровню, КД, хитам, редкости, цене.
- Карточки в духе официального статблока: характеристики, спасброски, особенности, легендарные действия, логово, региональные эффекты, художественное описание.
- Классы 2014: таблица прогрессии, умения по уровням, все подклассы (официальные и из Unearthed Arcana — с пометкой).
- Работает на телефоне. Тёмная тема подстраивается под систему. Выбранная редакция запоминается.
- Статический сайт: открыл в браузере — и всё. GitHub Pages, Netlify или просто локальный HTTP-сервер.

## Броски и экран мастера

- **Кликабельные броски.** Формулы («2к8+10»), бонусы атаки («+17 к попаданию»), навыки, инициатива, модификаторы и спасброски в карточках — кнопки. Клик бросает кубы (честный генератор браузера), результат появляется внизу справа. Shift — преимущество, Alt/Ctrl — помеха; режим «крит» удваивает кости урона. Код: `dice.js`, `dice.css`.
- **Экран мастера** (пункт «Экран мастера» в меню). Свободно перетаскиваемые и растягиваемые панели: инициатива (монстров можно добавить кнопкой «В инициативу» на карточке — хиты, КД и бросок инициативы подставятся), кубики, запись из базы, состояния, заметки, счётчики, единицы и монеты, игровое время, картинка по ссылке. Несколько экранов-вкладок, всё хранится в браузере; «Экспорт»/«Импорт» сохраняет в файл. В инициативе: вкладки-схватки (можно заготовить заранее и нажать «Начать бой»), урон по типам с учётом сопротивлений, иммунитетов и уязвимостей, состояния с длительностью в раундах, свои монстры (библиотека хранится в браузере). Картинки можно загружать с компьютера. Код: `dmscreen.js`, `dmpanels.js`, `dmscreen.css`.

2. Выберите редакцию **2014** или **2024** (кнопки слева в шапке).

## Запуск у себя

Обычный статический сайт: `index.html` + JSON. Из-за `fetch()` его нужно открывать через HTTP, а не как `file://`.

```bash
git clone https://github.com/Usarname-1/dndbase.git
cd dndbase
python3 -m http.server 8080
```

Дальше откройте `http://127.0.0.1:8080/`.

Подойдёт любой статический хостинг: GitHub Pages, Cloudflare Pages, Netlify.

### Формат записей

Общие поля у каждой записи: `slug` (уникален внутри файла), `name_ru`, `name_en`, `sources`, `url` (страница-оригинал), `blocks` (текст).

Только в `data14/`:

| Поле | Значение |
| --- | --- |
| `edition` | всегда `"2014"` |
| `id` | номер записи на сайте-источнике |
| `url_2024`, `id_2024` | ссылка на версию 2024, если она есть (по ним строятся ссылки между редакциями) |
| `homebrew` | `true` для Homebrew / UA записей |

Блоки текста (`blocks`) бывают типов: `paragraph`, `heading`, `list`, `table`, `quote`, `embed` (ссылка на вложенную карточку). Внутри текста используется простая разметка: `**жирный**` и `*курсив*`.

Специфичные поля: у монстров 2014 — `ac`, `hp`, `speed`, `abilities`, `cr`, `alignment`, `sections` (особенности, действия, реакции, легендарные действия, логово…) и `lore`; у классов 2014 — `table`, `core_traits`, `features`, `subclasses`; у заклинаний — `level`, `school`, `classes`, `components`, `higher` и т. д.

## Картинки и подсказки

- **Картинки** (`img/`, ~210 МБ) взяты из зеркал 5etools ([5etools-img](https://github.com/5etools-mirror-3/5etools-img) для 2024 и [5etools-2014-img](https://github.com/5etools-mirror-3/5etools-2014-img) для 2014) и лежат прямо в этом репозитории. Для каждой записи картинка ищется по английскому названию без учёта книги: сначала в своей редакции, затем в другой; у монстров без арта берётся токен (круглый портрет). Всё сжато до 640 px (токены до 400 px). Нечёткого сравнения названий нет намеренно: оно путает похожие предметы. Пересборка: `python3 tools/build_images.py <путь к 5etools-img> <путь к 5etools-2014-img>`.
- **Ссылки-подсказки** в тексте карточек: `links.js` + `data/links.json`, `data14/links.json`. Пересборка индексов после правки данных: `python3 tools/build_links.py`.

## Известные ограничения

- Нет Homebrew-контента. Картинки есть не у всех записей (только там, где они нашлись в зеркалах 5etools).
- В 2014 нет отдельного раздела снаряжения и глоссария (см. «Правила и статьи»).
- Мелкие подпункты умений классов 2014 (боевые стили, метамагия, воззвания) наследуют уровень родительского умения.
- Если нашли ошибку разбора или перевода — откройте Issue с ссылкой на запись.

## English

Unofficial **Dungeons & Dragons 5th Edition** reference in **Russian**. Covers both the **2014 (5e)** and **2024** rulesets: bestiary / monsters, spells, classes, species / races, backgrounds, feats, magic items, equipment, a 2024 rules glossary and 2014 rules articles.

- Live site: [https://usarname-1.github.io/dndbase/](https://usarname-1.github.io/dndbase/)
- Edition switch (2014 / 2024) with cross-links between versions of the same entry
- Search in Russian **and** English (`Fireball` finds «Огненный шар»)
- Filters for CR, type, school, rarity, source, and more
- Book-style statblocks, no account required, static GitHub Pages app
- Data is plain JSON (`data/` for 2024, `data14/` for 2014) and easy to reuse

Not affiliated with Wizards of the Coast or Hasbro.
